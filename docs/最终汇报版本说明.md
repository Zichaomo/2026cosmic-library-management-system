# 宇宙图书馆管理系统：最终汇报版本说明

> ## ⚠️ 口径更正（2026-10-16）：标题里的「最终版」已不成立
>
> 课程设计要求**只使用教材附录 C 列出的 66 个库函数**（见 [`课程允许函数清单.md`](课程允许函数清单.md)），而本版本大量使用清单外的 **Win32 控制台 API、宽字符库、`BCryptGenRandom`、`time.h`、`memset`/`snprintf`/`strncpy`** 等，属于重大越界，**代码需要重构**；界面也另有优化空间。
>
> 因此本文所述的「最终汇报版本 / v1.0.0 / 57 项测试通过」只代表**重构前的历史状态**，不作为交付口径。项目当前状态与重构方向见仓库根目录 [`README.md`](../README.md)。正文保留原样，供追溯。

## 本轮升级结果

最终汇报版本保留原有键盘操作，并新增鼠标与滚轮交互：

- 左键点击欢迎页、登录页、注册页和工作台按钮。
- 左键选择列表记录，双击执行当前页面的主要操作。
- 滚轮向上或向下移动列表选中项，超过 15 行时自动翻页。
- 右键等同于 `Esc`，用于返回上一页或退出当前页面。
- 输入表单可用鼠标切换输入框，并可点击“确认提交”“返回”等按钮。
- 没有数据或状态变化时不重复刷新，避免终端画面闪烁。

## 视觉调整

- 顶部增加 `BUCT / 0Error`、系统标题与 `FINAL v1.0.0` 标识。
- 管理员和读者工作台使用带编号的宽菜单，当前选项显示 `▶`。
- 中文与英文混排时按终端实际显示宽度居中，减少按钮文字偏移。
- 每个页面的状态栏直接显示鼠标和键盘操作方法。

## 馆藏扩充

默认馆藏由 5 本扩充到 20 本，覆盖：

- C 语言、数据结构、算法、操作系统和计算机网络；
- STM32、自动控制、信号与系统和数字电子技术；
- 中国文学、外国文学和自然科学读物。

新增演示书使用 `BUCT-*` 馆藏编号，避免把虚构编号冒充真实 ISBN。

## 运行方式

在项目根目录打开终端：

```powershell
mingw32-make
.\build\library.exe
```

管理员演示账号：

```text
账号：admin
密码：admin123
```

建议把终端调整到至少 `100 × 30`，运行展示效果最佳。

## 推荐汇报路线

1. 展示欢迎页，说明键盘与鼠标双交互。
2. 使用管理员账号登录，展示宽菜单和角色分流。
3. 进入图书管理，滚动浏览 20 本馆藏。
4. 展示新增图书、增加副本、停借与恢复。
5. 展示借阅、归还、续借、罚款和预约队列。
6. 打开统计报表，说明 CSV 持久化和多终端同步。
