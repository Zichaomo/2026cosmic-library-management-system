# 功能、交互与业务规则

## 已实现范围

当前17页为欢迎、登录、注册、管理员工作台、读者工作台、图书目录、我的借阅、我的预约、我的罚款、图书管理、新增/编辑图书、读者管理、借阅管理、办理借书、预约管理、罚款管理、统计报表。编辑图书复用原新增页，不另计页数。

管理员管理图书、读者和流通；读者只访问自己可见的借阅、预约和罚款。注册、登录、冻结/解冻和提交前的权限检查已实现。

图书支持中文、全拼、首字母、混合输入检索、新增、编辑ISBN/书名/作者、增加副本、停借/恢复。编辑保留内部书ID、库存、状态和历史关联；重复ISBN拒绝，原资料变化时拒绝过期表单覆盖。副本通过独立操作增加，不在资料编辑时修改。

## 名称办理和列表

读者从目录选中图书后借书/预约，不输入ID。管理员可输入读者账号/姓名及书名/ISBN，也可从目录携带已选图书。账号或ISBN完全一致优先，再按完全一致姓名/书名，最后模糊检索。多结果必须选候选；读者显示姓名/账号，图书显示书名/作者/ISBN。修改输入后原选择绑定失效，提交重新校验身份、库存与权限。确认框显示名称和账号，内部仍用稳定ID关联。

借阅S循环全部、在借、已还、逾期、7天内到期、到期提醒；P切换记录顺序、应还日期升序/降序，同日期按ID升序。角色范围、检索、筛选和排序可组合。

工作台显示7天内到期与逾期数量，D进入包含逾期的提醒列表；今天至第7天含边界，第8天不计入，今天应还不算逾期。读者仅统计自己，管理员统计全体。提醒随页面/事件刷新，不是后台通知。

列表每页8项，超过一页显示ANSI位置滚动条，方向键、PgUp/PgDn、Home/End控制。不支持鼠标拖拽或滚轮。检索关联借阅/预约/罚款的书名、作者、读者账号和姓名，不搜索密码散列、盐，不跨越角色权限。

## 流通规则

- 借期30天，最多同时在借5本；重复借同一本拒绝，图书停借或无可借副本拒绝。冻结账号或未付罚款累计达到1000分限制新借阅。不要额外写成“有任何逾期就一律禁止新借书”，现有实现不是该规则。
- active借阅可续借一次，从原应还日期延15天；已逾期、读者状态不允许或存在开放预约等情况拒绝。
- 应还日当天不逾期，次日开始每自然日50分，归还时生成罚款；模拟缴费不接真实支付。
- 有普通可借副本时不预约；同一读者重复在借/开放预约同一本拒绝。排队按预约ID先后分配，待取副本已从普通可借库存扣除，领取不重复扣减。
- 待取保留至分配日加2天（含截止日），过期/取消后释放副本并继续分配。相关状态更新由进入/刷新与操作检查触发，没有无按键后台调度。
- 每次提交重读并验证保存状态；重复归还、取消、缴费等拒绝重复处理。

## 视觉约定

固定120×35，暖白底、石灰色未选中、鼠尾草浅绿选中，选中按钮左侧“> ”，文字位置稳定、无额外矩形焦点框。登录/返回和输入框均只在获得焦点时变色。欢迎标题标语居中，工作台左导航右概览。每次有效按键完整补画但不清屏；F5清屏重画以修复缩放损坏。字体与真实输入法观感仍需用户终端验收。
