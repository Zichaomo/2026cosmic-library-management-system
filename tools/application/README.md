# 当前 C 应用

界面与交互位于 `src/ui_next/`，流通业务位于 `src/migration/library.c`，认证和仓储由同目录模块提供。默认构建目标是当前应用，历史实现位于 `legacy/`，不参与链接。

在项目根目录执行 `make run`；`make test-application` 使用独立样本验证业务和界面，并检查新进程读取持久化记录。`tools/preview/` 是内存原型，不作为业务程序入口。

使用与边界统一维护在[运行说明](../../docs/运行说明.md)、[功能与交互](../../docs/功能与交互.md)、[架构与数据](../../docs/架构与数据.md)和[验证记录](../../docs/验证记录.md)，本目录不再重复维护阶段日志或本地截图工具的操作步骤。
