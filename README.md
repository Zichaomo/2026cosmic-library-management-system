# 宇宙图书馆管理系统

Windows 控制台 C 语言课程设计，提供管理员与读者两种角色，以及图书检索、借还续借、预约、罚款和统计功能。数据采用 UTF-8 CSV 与两槽快照保存。

## 快速启动

安装 Windows GCC/MinGW 和 GNU Make，并将 `gcc`、`make` 加入 PATH。在项目根目录执行：

```text
make run
```

终端须支持 ANSI 真彩色，可见区域至少 **120 列 × 35 行**，尺寸和字体由使用者调整。Makefile 在启动 C 程序的同一条 `cmd` 命令中执行 `chcp 65001`，确保使用 UTF-8。

首次运行提供以下演示账号和 20 种样例图书；再次启动保留已有数据。

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | admin | admin123 |
| 读者 | reader001 | reader123 |

| 常用命令 | 作用 |
| --- | --- |
| `make` | 编译到 `start/CosmicLibrary.exe` |
| `make run` | 编译、首次准备数据并运行 |
| `make run-compiled` | 使用已有 exe 运行 |
| `make test` | 运行当前 C 测试和新进程持久化检查 |
| `make diagnose-console` | 检查终端编码及输出 |

程序需要数据目录参数，不支持无参数双击进入。完整步骤、独立演示目录与错误处理见[运行说明](docs/运行说明.md)。

## 当前功能

- 按中文、拼音全拼、首字母或混合输入检索；列表提供键盘位置滚动条。
- 按读者账号/姓名、书名/ISBN 办理借书或预约，多结果需明确选择。
- 借阅状态筛选、应还日期排序、图书资料编辑、到期和逾期提醒。
- 借还续借、预约排队、模拟缴费、读者冻结与统计。

Tab/方向键导航，Enter 确认，F1 帮助，F5 刷新，Ctrl+Q 退出。详情见[功能与交互](docs/功能与交互.md)。

## 实现与数据边界

业务、界面和存储均由 C 程序实现，函数范围按[课程允许函数清单](docs/课程允许函数清单.md)核对。Makefile 负责 GCC 编译、启动前设置代码页，以及首次通过 `mkdir`/`copy` 准备数据目录；这些命令不由 C 程序调用。运行不依赖 Python、PowerShell 脚本或 .NET 启动器。

默认数据位于 `build/library-data`。这是单进程程序，同一数据目录只能由一个实例使用，需人工保证。快照支持已验证的进程中断恢复，不保证断电落盘；不要手改已建立快照后的 CSV，也不要清空 `build/`。

## 仓库内容

`src/`、`include/` 为当前实现，`tests/` 和 `tools/` 保留 C 测试、原型、探针及拼音数据来源；`resources/empty-data/` 是初始格式模板。`legacy/` 为历史参照，不参与当前应用编译。

exe、真实运行数据及 Python/PowerShell/C# 开发工具仅留本地，不纳入当前版本。Git 历史保留，旧提交中的工具仍可查阅。Gitee 页面语言比例与当前源码可能不同步，核对仓库内容时应检查默认分支的文件清单。
