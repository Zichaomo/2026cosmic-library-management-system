# 图书馆管理系统（Library Management System）产品需求文档（PRD）

- 版本：v0.1（草稿）
- 状态：需求已对齐，待开发
- 面向：课程设计 / 个人项目（Windows 控制台、纯 C 语言、CSV 持久化）

---

## 1. 项目概述

### 1.1 背景与目标

构建一个 **仅使用 C 语言**、运行于 **Windows 控制台** 的图书馆管理系统。系统以「字符画图形界面（TUI）」呈现：使用框线字符、颜色与鼠标光标模拟桌面窗口/菜单体验，具备真实的鼠标点击选择能力，同时完整支持键盘操作。

目标：

1. 覆盖图书馆业务核心闭环：图书管理 → 读者管理 → 借书/还书 → 续借/预约 → 逾期罚款 → 统计报表。
2. 全部源代码为 C 语言，不依赖第三方库（Windows SDK 自带的 C API 除外）。
3. 控制台图形化界面，鼠标可点击菜单/按钮/列表，交互友好。
4. 数据持久化到文本 CSV 文件，重启不丢失，且可直接用记事本/Excel 查看。

### 1.2 约束与已确认决策

| 项 | 决策 |
|---|---|
| 开发语言 | 仅 C 语言（C99/C11），不使用 C++/C#/Python/JS 等任何其他语言 |
| 运行平台 | Windows 控制台（Windows 10/11） |
| 鼠标能力 | 使用 Win32 Console API 的 `ReadConsoleInput` 鼠标事件，**可点击** |
| 数据持久化 | 纯文本 CSV 文件 |
| 功能范围 | 全功能版本（图书、读者、借还、续借、预约、罚款、统计等） |

> **关于"纯 C 环境"的说明（用户提问）：**
> 是。选项 1（Windows 控制台 + Win32 API）**可以在纯 C 环境下使用**——
> 全部代码仍用 C 语言编写，Win32 控制台 API（`windows.h` 中的 C 函数）只是
> Windows SDK 提供的一套 C 接口，由 Visual Studio / MinGW 自带，**不是另一种语言**。
> 因此既满足"只用 C 语言"，又能在控制台实现鼠标点击。
> ⚠️ 唯一限制：如果进一步要求"**只用 C 标准库（`<stdio.h>` 等），完全不调用操作系统 API**",
> 则标准 C 没有控制台鼠标事件接口，**鼠标点击将无法实现**，只能退化为 ANSI 转义码 + 键盘 TUI。
> 本 PRD 按「允许 Win32 C API、允许鼠标」撰写。

### 1.3 术语

- **图书（Book）**：书目信息（ISBN、书名等），一个书目可拥有多个馆藏副本。
- **副本（Copy）**：可借出/归还的物理单元，跟踪在架/借出状态。
- **读者（Reader）**：注册用户，可借阅、预约、缴纳罚款。
- **借阅单（Loan）**：一次借阅/归还记录。
- **预约（Reservation）**：副本全部借出时排队等待。
- **罚款（Fine）**：逾期自动生成，需读者缴纳。
- **管理员（Admin）**：系统管理用户，初始账号首次启动时种子化创建。

## 2. 用户角色与权限

| 角色 | 权限 |
|---|---|
| 管理员（admin） | 图书/作者/出版社/分类管理；读者管理与冻结；借书/还书/续借处理；预约处理；罚款管理与收款；统计报表；数据导出 |

初始管理员：`admin / admin123`（首次启动自动创建，提示修改密码）。

## 3. 功能需求

优先级：**P0**（上线必需） / **P1**（重要） / **P2**（增强，可后置）。

### 3.1 账号与登录（P0）

| 编号 | 需求 |
|---|---|
| FR-101 | 启动进入欢迎页，提供「登录 / 注册读者 / 帮助 / 退出」四个可点击按钮 |
| FR-102 | 登录表单：账号 + 密码（密码显示为 `*`），支持 Tab 切换字段、Enter 提交、Esc 返回 |
| FR-103 | 登录失败提示原因（账号不存在/密码错误/账号冻结），不清空已输入账号 |
| FR-104 | 注册（读者）：姓名、学号/工号（唯一）、密码+确认密码、联系方式；字段非空、格式、唯一性校验 |
| FR-105 | 密码不以明文存储：使用「FNV-1a 散列 + 随机盐」字符串存储（课程级，非加密安全用途） |
| FR-106 | 会话内记录当前用户与角色；退出登录返回欢迎页 |

### 3.2 控制台图形界面框架（P0，贯穿全系统）

| 编号 | 需求 |
|---|---|
| FR-201 | 界面由「标题栏 / 菜单栏 / 内容区 / 状态栏」组成，使用框线字符（`┌ ─ ┐ │ └ ┘`）绘制 |
| FR-202 | 所有菜单项、按钮、列表行支持**鼠标单击**命中（按字符坐标矩形判定）；悬停高亮、按下反馈 |
| FR-203 | 列表支持**鼠标滚轮**滚动；支持 PageUp/PageDown、Home/End、方向键 + Enter |
| FR-204 | 键盘可完成全部功能（鼠标是增强，不是唯一入口） |
| FR-205 | 全局快捷键：`F1` 帮助、`F5` 刷新、`Esc` 返回上级、`Ctrl+Q` 退出 |
| FR-206 | 控制台窗口自适应：获取 `GetConsoleScreenBufferInfo` 尺寸，过小时提示调整到最小 100×30 |
| FR-207 | 中文显示：源码 UTF-8，启动 `SetConsoleOutputCP(CP_UTF8)` 或使用 `WriteConsoleW`；终端不支持时回退 GBK(CP936) 方案 |

### 3.3 图书管理（P0，管理员）

| 编号 | 需求 |
|---|---|
| FR-301 | 图书字段：ISBN、书名、作者、出版社、出版日期、分类、定价、馆藏总数、可借数、馆藏位置、简介、状态（在架/停借/注销） |
| FR-302 | 操作：新增 / 详情 / 编辑 / 删除（有未还副本时禁止删除，只能「停借」） |
| FR-303 | 检索：按 ISBN、书名、作者、分类**模糊匹配**；结果分页列表 |
| FR-304 | 作者 / 出版社 / 分类为独立字典表，可增删改；删除时若有图书引用则提示并阻止 |
| FR-305 | 「多副本」：新增图书时录入副本数，总数=可借数；借出/归还自动增减可借数 |
| FR-306 |（P1）CSV 批量导入 / 导出图书 |

### 3.4 读者管理（P0，管理员）

| 编号 | 需求 |
|---|---|
| FR-401 | 读者列表 + 检索（学号/姓名/联系方式） |
| FR-402 | 管理员可新增/编辑读者资料、冻结/解冻账号、注销读者 |
| FR-403 | 查看单个读者的借阅历史、当前借阅、预约队列、欠款总额 |
| FR-404 | 冻结状态下不可借书、不可续借；解冻后恢复 |

### 3.5 借阅 / 归还 / 续借（P0）

| 编号 | 需求 |
|---|---|
| FR-501 | 借书：选择读者 + 图书（或输入 SN/ISBN），校验：图书存在且有可借副本、读者正常、未超借阅上限（默认 5 本）、未冻结 |
| FR-502 | 借期默认 30 天（可配置），生成借阅单：ID、读者、图书副本、借出时间、应还时间、状态 |
| FR-503 | 还书：支持按借阅单号或图书条码归还；归还时计算是否逾期并自动生成罚款单 |
| FR-504 | 续借：有借阅记录且未逾期时可续借 **1 次、15 天**；预约队列有人时禁止续借 |
| FR-505 | 逾期列表：全局展示所有逾期未还记录，突出红色 |
| FR-506 |（P1）到期提醒：登录时状态栏提示 N 本应还、M 本逾期 |

### 3.7 罚款（P1）

| FR-702 | 读者可「缴纳」罚款（模拟支付，记录缴费时间）；管理员也可代收 |

### 3.8 统计报表（P1）

| 编号 | 需求 |
|---|---|

## 4. 界面与交互设计

### 4.1 整体风格

- 控制台 TUI：框线窗口 + 颜色主题（默认蓝底白字，可配置）。
- 每个业务页面是一个「窗口」，窗口之间通过点击菜单/按钮切换。
- 底部状态栏显示当前用户、角色、系统时间、快捷提示。
- 所有操作结果（成功/失败/警告）以弹窗或状态栏消息反馈。

### 4.2 鼠标实现要点（Win32）

| 能力 | 实现方式 |
|---|---|
| 单击 | `ReadConsoleInput` → `MOUSE_EVENT` → 与控件矩形做命中检测 |
| 悬停高亮 | 每次输入后重绘当前元素（无鼠标移动事件时可合并为单击前高亮） |
| 滚轮 | 检测 `dwEventFlags & MOUSE_WHEELED`，滚动列表/分页 |
| 双击 | `MOUSE_EVENT` 双击标志：列表行「快速进入详情」 |
| 窗口缩放 | `WINDOW_BUFFER_SIZE_EVENT` 后重排布局 |

### 4.3 页面清单（导航地图）

```
欢迎页（登录/注册/帮助/退出）
├── 管理员主菜单
│   ├── 图书管理（列表/检索/详情/新增/编辑）
│   ├── 字典管理（作者/出版社/分类）
│   ├── 读者管理（列表/详情/冻结/注销）
│   ├── 借阅管理（借书/还书/续借/逾期列表）
│   ├── 预约管理（排队队列）
│   ├── 罚款管理（未缴/已缴/收款）
│   └── 统计报表（各报表/导出）
└── 读者个人中心
    ├── 图书检索与详情
    ├── 我的借阅（含续借/还书申请）
    ├── 我的预约（取消/查看）
    └── 我的罚款（缴费记录）
```

## 5. 数据设计（CSV）

### 5.1 通用约定

- 数据目录：`data/`；UTF-8 编码（带 BOM，便于记事本/Excel 查看）。
- 首行为表头；字段间 `,` 分隔；含逗号/引号/换行的字段按 RFC 4180 转义。
- 启动时全部载入内存；每次写操作后**原子保存**（先写 `*.tmp` 再 `rename`），防止崩溃损坏。
- 自增 ID 记录在 `meta.csv`。

### 5.2 表结构（字段名）

**books.csv**
`id, isbn, title, author_id, publisher_id, category_id, pub_date, price, total_copies, available_copies, location, status, description, created_at`

**readers.csv**
`id, reader_no, name, password_hash, salt, phone, email, status(正常/冻结/注销), created_at`

**authors.csv**
`id, name, birth_year, nationality, description`

**publishers.csv**
`id, name, address, phone`

**categories.csv**
`id, name, parent_id`

**loans.csv**
`id, book_id, copy_no, reader_id, borrow_date, due_date, return_date, status(借出/已还/逾期/续借), renew_count`

**reservations.csv**
`id, book_id, reader_id, reserve_date, expire_date, status(排队/可借/已取/过期/取消)`

**fines.csv**
`id, reader_id, loan_id, amount, created_at, status(未缴/已缴), paid_at`

**meta.csv**
`key, value`（`next_reader_id`、`next_book_id`、`loan_days=30`、`fine_per_day=0.5` 等配置项）

## 6. 技术架构

### 6.1 模块划分（纯 C，单工程）

```
src/
├── main.c                 // 入口：初始化控制台、事件循环、全局状态
├── ui/
│   ├── console.c          // 平台封装：输出/颜色/光标/清屏（Win32 实现）
│   ├── input.c            // 键盘 + 鼠标事件解析与分发
│   ├── widget.c           // 控件：按钮、列表、表单、弹窗、状态栏
│   ├── screen.c           // 页面路由与布局管理
│   └── theme.c            // 颜色与样式
├── core/
│   ├── auth.c             // 登录/注册/会话
│   ├── book.c             // 图书与副本逻辑
│   ├── reader.c           // 读者管理
│   ├── loan.c             // 借还/续借/逾期
│   ├── reservation.c      // 预约队列
│   ├── fine.c             // 罚款计算与缴费
│   ├── search.c           // 检索与过滤
│   └── stats.c            // 统计报表
├── data/
│   ├── csv.c              // 通用 CSV 解析/写出（转义）
│   └── repository.c       // 各实体加载/保存/原子写
└── utils/
    ├── string.c / date.c / hash.c / file.c / validator.c
```

### 6.2 数据流

```
[鼠标/键盘事件] → input.c 解析 → screen.c 命中当前窗口控件
  → 调用 core/ 业务函数 → 校验 + 内存更新
  → repository 原子写回 CSV → 重绘界面反馈
```

### 6.3 关键技术点（Win32）

- `SetConsoleMode(handle, ENABLE_MOUSE_INPUT | ENABLE_EXTENDED_FLAGS | ENABLE_WINDOW_INPUT)`
- `ReadConsoleInputW` 读取 `MOUSE_EVENT / KEY_EVENT / WINDOW_BUFFER_SIZE_EVENT`
- `GetConsoleScreenBufferInfo` 取窗口尺寸；`SetConsoleCursorPosition` 定位
- `SetConsoleTextAttribute` 设置前景/背景色
- `WriteConsoleW` / `FillConsoleOutputCharacter` 绘制框线与文本
- `ScrollConsoleScreenBuffer` 实现列表滚动
- 编译：Visual Studio 或 `gcc main.c ... -o library.exe`（MinGW），入口用 `wmain`（宽字符）

### 6.4 跨平台预留

将平台相关调用集中在 `ui/console.c` + `ui/input.c`，接口保持"绘制、读事件"抽象；
后续如需 Linux 版，可用 ncurses 另写后端，业务层无需改动。

### 6.5 性能与容量

- 内存模型：动态数组，初始容量 128，按需扩容。
- 上限：图书/读者各 ≤ 10,000，借阅/预约/罚款 ≤ 100,000（可配置）。
- 检索：默认线性扫描；ISBN/学号可建立简单哈希索引（P2 优化）。

## 9. 验收标准

1. 全流程可走通：登录 → 新增图书 → 注册读者 → 借书 → 模拟到期 → 还书（自动生成罚款）→ 缴费 → 预约排队 → 统计报表。
2. 鼠标可完成所有高频操作（登录、菜单、新增、借还、滚动列表、缴费）；键盘可完整替代鼠标。
3. 所有数据写入 CSV，程序重启后数据完整恢复，CSV 可直接查看。
4. 无崩溃：空数据、错误格式、重复 ISBN/学号、越界预约等均有明确提示。
5. 逾期罚款、续借次数、借阅上限、预约顺延等规则按配置生效并可验证。

## 10. 风险与假设

| 风险/假设 | 说明与应对 |
|---|---|
| 「纯 C」解释差异 | 本 PRD 假设允许 Win32 C API；若必须仅标准 C 库，则鼠标点击不可实现，降级为 ANSI/键盘 TUI（见 1.2） |
| 中文显示 | 依赖控制台代码页与字体；处理方案见 FR-207，必要时提供 GBK 模式 |
| 多进程/并发 | 单机单用户使用，不做并发锁与权限隔离 |
| 密码安全 | 使用 FNV-1a+盐散列，仅为课程级防明文；不作加密安全认证 |
| CSV 规模 | 万级数据性能达标；十万级需改为二进制或数据库（超出本版范围） |
