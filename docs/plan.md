# 开发计划

更新：2026-10-23。使用方法见[运行说明](运行说明.md)，现状与证据见[文档索引](README.md)。

## 已完成

- 教材函数与头文件范围核对，基础工具、CSV、认证、流通和 17 页界面迁移；旧实现隔离到 `legacy/`。
- 120×35 暖色界面、统一焦点样式、中文编辑、按键重绘和 F5 刷新。
- 中文/拼音检索、关联名称查找、键盘位置滚动条。
- 按姓名/账号和书名/ISBN 借书或预约，重名候选选择与名称确认。
- 借阅筛选排序、图书资料编辑、工作台到期提醒。
- 当前版本移除 Python/PowerShell/C# 工具跟踪，保留本地副本和 Git 历史。
- 直接编译运行 C 主程序，同 cmd 设置 UTF-8；用户已确认原终端启动可用。
- 现行 297 项 C 断言、新进程持久化检查和源码审计通过；结果日期见[验证记录](验证记录.md)。

## 后续顺序

1. 人工确认中文输入法、长字段编辑、字体列宽、窗口缩放和 F5 恢复。
2. 使用独立演示目录，分别走通管理员与读者借还预约、名称候选、编辑、筛选、提醒和重启持久化。
3. 修复实际发现的问题，再由用户选择是否增加新功能。
4. 程序认可后再安排 PPT、报告或视频；目前优先完善程序。

## 暂缓功能

多终端自动同步、并发写入、空闲后台提醒、鼠标和滚轮尚未实现。同一数据目录由使用者人工保证单实例。

此前候选 C（个人资料/密码维护）、E（收藏书单）、F（更细统计与导出）、G（分类/出版社/馆藏位置）尚未获选，不自动实施。已获选的 A（筛选排序）、B（图书编辑）、D（到期提醒）已完成；这些字母是原需求编号，具体操作键见[功能与交互](功能与交互.md)。

## 维护约定

保留已有业务期限、罚款口径和数据格式。每轮程序修改后完成相关检查，更新 `start/CosmicLibrary.exe`；不清空用户数据，不强行结束运行实例。

按功能分批提交并保留 Git 历史，仅在用户要求时推送。当前提交不纳入 exe、真实运行数据和本地开发脚本；文档与实际代码、命令及已执行证据保持一致。
