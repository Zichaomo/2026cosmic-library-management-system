# 宇宙图书馆管理系统

纯 C、Windows 控制台、CSV 持久化的课程设计项目，包含管理员和读者登录、图书与读者管理、借还续借、预约、罚款和统计。

当前为待完成课程函数约束重构的版本。主体代码仍依赖 Win32、宽字符库和 BCrypt，不能作为合规最终版提交。

## 文档入口

- [重构计划](docs/plan.md)：当前基线、保留业务、六步实施顺序、验收要求和多终端专项。
- [课程允许函数清单](docs/课程允许函数清单.md)：附录 C 66 个函数与正文补充 9 个函数，以及头文件和实现边界。

2026-10-21 已清理含失效信息的历史 Markdown，并将有效重构范围归入计划。旧文档中的机器路径、最终版标签和测试数量不代表当前验收状态。

## 代码结构

- `src/`：入口、应用流程、界面、业务、仓储和工具实现。
- `include/`：模块接口；已有 `base_types.h`，尚未接入主体。
- `tests/`：认证、流通和 UI 测试，仍需迁移。
- `tools/preview/`：ANSI 界面原型，未接入业务，尚有清单外调用。
- `data/`：运行时生成的数据，已忽略；重构测试使用独立副本。
- `Makefile`：构建规则，shell 和测试路径问题列入计划。

## 当前构建说明

目标工具链为 Windows GCC / MinGW。旧构建仍链接 BCrypt；下面是已有文档记录的临时构建方式，本轮文档整理没有重新执行验证：

```powershell
mingw32-make SHELL=cmd.exe
.\build\library.exe
```

现有 `make test` 规则仍有路径兼容问题，修复后再统一为一条测试命令。历史测试通过数量不能替代重新验收。

演示管理员账号为 `admin` / `admin123`。当前运行程序会读写运行数据，体验或回归时请使用独立数据副本。
