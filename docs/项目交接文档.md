### 2.2 已确定的两条口径（不必再纠结）

1. **ANSI 转义序列可用** —— 用 `printf` 打印 `"\033[2J"`（清屏）、`"\033[10;20H"`（定位）、`"\033[31m"`（上色）来控制画面。理由是它输出的是**字符串**、不是库函数。**这是保留彩色 TUI 的唯一依据**（教材里没有任何光标/颜色/清屏函数）。
2. **类型头自己写一套** —— 不包含 `<stdbool.h>` `<stdint.h>` `<stddef.h>` `<limits.h>` `<errno.h>`，改为项目自己的 `typedef` / `#define`（方案见 [`课程允许函数清单.md`](课程允许函数清单.md) 第 9 节，已在本机实测）。

## 4. 现状架构 → 重构后的对应关系

| 现在（越界） | 重构后（合规） |
| --- | --- |
| `WriteConsoleW` 输出宽字符 | `printf("%s", utf8_bytes)`，程序启动先 `chcp 65001` 或要求终端为 UTF-8 |
| `SetConsoleCursorPosition` | `printf("\033[%d;%dH", y, x)` |
| `SetConsoleTextAttribute` | `printf("\033[3%dm")` / `"\033[4%dm"`（16 色映射见 §7.3） |
| `console_clear`（FillConsoleOutput） | `printf("\033[2J\033[H")` |
| `GetConsoleScreenBufferInfo` 取窗口尺寸 | 固定 `100 × 30`（或读环境变量 / 命令行参数），越界时提示用户调整终端 |
| `ReadConsoleInputW` 键盘事件 | `getch()` 逐字节读；方向键是**两次** `getch()`（前缀 `0xE0` 或 `0x00`） |
| 鼠标点击 / 滚轮 | **放弃**（无合规实现路径），交互降到纯键盘 |
| `WINDOW_BUFFER_SIZE_EVENT` 缩放重排 | 放弃（固定尺寸布局） |
| `GetModuleFileNameW` 定位 `data\` | 改为相对当前工作目录 `data\`（或从 `argv[0]` 用字符串函数手工推），并要求在项目根目录运行 |
| `wchar_t` 字符串 + `wcs*` 函数 | `char` + UTF-8 字节串；**长度/宽度/截断要自己写 UTF-8 版本** |
| `BCryptGenRandom` 生成盐 | `rand()`（教材第 64 页有依据） |
| `time_t now = time(NULL)` + `strftime` | `time()` 合法可留；**年月日换算自己写**（闰年、月天数） |
| `memcpy` / `memset` / `strncpy` | 手写 `for` 循环 / `strcpy` + `strlen` 组合 |
| `sscanf` 解析 CSV 里的日期 | 手写按 `-` / `:` / 空格切分 + `isdigit` 校验 |
| `errno` 判错 | 看返回值 / `NULL` / `feof()` / `ferror()` |

## 6. 目标形态与设计约束

**必须保留**：

1. 中文界面与中文数据（CSV 内容仍是中文）。
2. **彩色 + 框线的 TUI 观感**（用 ANSI 转义实现，16 色映射见 §7.3）。
3. **按键立即响应**（`getch()`），无需回车的菜单/翻页手感。
4. 17 个页面、导航关系、状态栏提示、焦点高亮。
5. 全部业务规则：借期 30 天、可续借 1 次 15 天、逾期 0.5 元/天、预约队列、停借/冻结、统计报表。
6. CSV 文件格式与旧数据**双向兼容**（含 BOM 与中文状态值）。
7. 编译零警告（现状就是 `-Wall -Wextra -Wpedantic` 干净通过，请保持）。

**可以放弃**：

1. 鼠标点击与滚轮。
2. 终端窗口尺寸自适应（改成固定 100×30，太小则提示）。
3. 宽字符 API、BCrypt、Win32 控制台模式操作。

**运行环境要求**（验收环境）：

- **Windows Terminal 或 VS Code 集成终端**（它们默认开启 VT 处理，ANSI 才能生效）。若必须在传统 conhost 窗口运行，需要先把注册表 `HKCU\Console\VirtualTerminalLevel` 设为 `1`（外部设置，不算代码越界）。
- 终端窗口 ≥ 100 × 30；代码页 UTF-8（程序内部 `system` 被禁，建议在启动脚本或终端设置里 `chcp 65001`；若允许，`system("chcp 65001")` 属越界，**不要用**）。

## 7. 分阶段实施计划

每个阶段结束都必须：**能编译、能运行、自检命令零输出**。不要一次性重写全部。

### P0 基础设施（先做，风险最低）

1. 新建 `include/base_types.h`：`typedef int bool; #define true 1 / #define false 0`，`u8/u16/u32/u64`。**不要**重复定义 `size_t` / `NULL` / `INT_MAX` / `EOF` / `FILE`（实测会报 `conflicting types`）。
2. 新建 `src/ui/term.c` + `include/ui/term.h`：ANSI 输出层，接口与现在的 `console.h` 一一对应（`term_goto(x,y)`、`term_color(fg,bg)`、`term_clear()`、`term_print(utf8)`），**内部只用 `printf`**。

## 8. 构建与测试（本机实测，2026-10-16）

工具链：`gcc (GCC) 16.1.0`（w64devkit）、`mingw32-make`，均在 PATH 中。Makefile 标志：`-std=c11 -Wall -Wextra -Wpedantic -g -Iinclude`，链接 `-lbcrypt`。

**⚠️ 两个已知的 Makefile 坑（本机实测）：**

1. `mingw32-make` 直接跑会失败：Makefile 的配方里用了 `@if not exist build mkdir build`（cmd 语法），但 w64devkit 自带的 `sh.exe` 在 PATH 里，make 会用 sh 执行配方 → `syntax error: unexpected end of file`。
   **可用命令**：`mingw32-make SHELL=cmd.exe`（编译成功，零警告）。
2. `mingw32-make SHELL=cmd.exe test` 仍然失败：`test` 目标直接写 `$(AUTH_TEST_TARGET)`（=`build/auth_tests.exe`），cmd 把 `/` 当开关，报 `'build' is not recognized`。
   **临时办法**：手动运行三个测试程序：

```powershell
mingw32-make SHELL=cmd.exe            # 编译 library.exe
.\build\auth_tests.exe                # 17 passed, 0 failed
.\build\circulation_tests.exe         # 51 passed, 0 failed
.\build\ui_tests.exe                  # 23 passed, 0 failed
.\build\library.exe                   # 运行 TUI（需要真实终端，≥100×30）
```

**建议**：P0 阶段顺手把 Makefile 修成可移植版本（`mkdir -p` 风格 + `./build/xxx` 路径），让 `make` / `make test` 在 PowerShell 与 MSYS 下都能直接跑；这不属于课程函数约束，但会显著降低后续每一轮的验证成本。

## 9. 陷阱清单（已经踩过或必然踩到）

1. **重定义 `size_t` 会直接编译失败**：`<stdio.h>` 已经定义过它，实测 `typedef int size_t;` → `error: conflicting types for 'size_t'`。`NULL` / `INT_MAX` / `EOF` / `FILE` 同理，直接用。
2. **自写 `bool` 时不要再包含 `<stdbool.h>`**：它的 `#define bool _Bool` 会与 `typedef int bool` 打架。
3. **`wchar_t` 有 283 处**，只改类型名不够：所有字符串处理、比较、拼接、显示宽度计算都要改成字节/UTF-8 语义。
4. **UTF-8 按字节截断会切碎汉字**：必须写"取前 N 个显示列"的工具函数（中文 3 字节 / 显示宽 2 列）。
5. **`getch()` 读方向键要调两次**：扩展键先返回 `0xE0` 或 `0x00` 前缀。映射见 §10。
6. **日期必须自己算**：`time()` 只给秒数；`localtime` / `strftime` / `sscanf` 全部越界。CSV 里的 `2026-09-05` 要自己解析，闰年与月天数自己写。
7. **`remove()` 不在白名单**：清空/删除文件不能用它。要清空就 `fopen(path, "w")` 再 `fclose`；要换名用白名单里的 `rename()`。测试里的 `DeleteFileW` / `RemoveDirectoryW`（Win32）也要一并改掉。
8. **原子保存可以保留**：现有实现是"先写 `.tmp` 再 `rename()`"，`rename` 在附录 C 表 C-5 里，合规。
9. **数据目录定位要换**：现在用 `GetModuleFileNameW` 取 exe 上两级 + `\data`（见 `app.c` 的 `resolve_data_directory`）。换成"相对当前工作目录 `data\`"最简单，但要在界面/文档里写明"必须在项目根目录启动"。
10. **测试自身也越界**：`tests/test_auth.c` 用了 `windows.h` + `DeleteFileW` + `SetConsoleOutputCP`；`test_ui.c`、`test_circulation.c` 也有。重构时一起改，否则自检通不过。
11. **`-lbcrypt` 要一起去掉**：`hash.c` 目前用 `BCryptGenRandom` 生成盐，改成 `rand()` 后 Makefile 的链接选项也要改，否则链接失败。
12. **中文输入**：`getch()` 按字节读，中文需要连续拼 3 字节；建议输入框只接受 ASCII（账号、密码、数字、日期都是 ASCII），中文只用于显示与 CSV 内容 —— 这样最省事，也最不容易出 bug。
13. **`gets` 虽然白名单里有**，但 C11 已移除、GCC 会告警；用 `fgets` 代替（同在附录 C 表 C-5）。

## 10. 越界写法 → 合规替代 速查表

| 现在用 | 替代写法 |
| --- | --- |
| `memset(p, 0, n)` | `for (i = 0; i < n; ++i) ((char *)p)[i] = 0;` |
| `memcpy(d, s, n)` | `for (i = 0; i < n; ++i) d[i] = s[i];` |
| `snprintf(buf, n, fmt, ...)` | 直接 `printf` / `fprintf`；必须在内存里拼串时用 `strcpy` + `strcat` 手工拼 |
| `strncpy(d, s, n)` | `strcpy` 前先 `strlen(s) < 容量` 检查，再 `strcpy` |
| `atoi` / `strtol` / `atof` | 手写循环：`isdigit` 判断 + `value = value * 10 + (c - '0')` |
| `sscanf(s, "%d-%d-%d", ...)` | 手写按字符切分 + `isdigit` 校验 |
| `strftime` / `localtime` | `time()` 取秒 → 自己算年月日（闰年 `(y%4==0 && y%100!=0) || y%400==0`） |
| `fflush(fp)` | 用 `fclose()` 收尾；需要中途落盘就关闭再打开 |
| `errno` 判错 | 看返回值 / `NULL` / `feof()` / `ferror()` |
| `BCryptGenRandom` | `rand()`（教材第 64 页），盐值拼成十六进制字符串 |
| `SetConsoleCursorPosition(h, {x,y})` | `printf("\033[%d;%dH", y + 1, x + 1)` |
| `SetConsoleTextAttribute(h, attr)` | `printf("\033[%dm\033[%dm", fg_code, bg_code)`（映射见 §7.3 / 下表） |
| 清屏 | `printf("\033[2J\033[H")` |
| `WriteConsoleW(h, wstr, ...)` | `printf("%s", utf8)` |
| `GetConsoleScreenBufferInfo` | 固定 100×30（常量或环境变量） |
| `ReadConsoleInputW` 方向键 | `c = getch(); if (c == 0xE0 \|\| c == 0) { switch (getch()) { case 72: 上; case 80: 下; case 75: 左; case 77: 右; case 71: Home; case 79: End; case 73: PgUp; case 81: PgDn; case 83: Delete; case 59: F1; case 63: F5; } }` |
| `Tab` / `Shift+Tab` / `Enter` / `Esc` / `Backspace` / `Ctrl+Q` | 直接判断 `9` / `0xE0,15` / `13` / `27` / `8` / `17` |
| 鼠标点击 / 滚轮 | 无合规方案，功能改为键盘等价操作 |

## 11. 验收标准（Definition of Done）

1. **合规**：§2.4 两条自检命令**零输出**；`grep -rn "windows.h\|wchar.h\|wctype.h\|bcrypt.h" src include tests` 无结果。
2. **可编译**：`mingw32-make`（或修好的可移植 Makefile）零警告通过，`-Wall -Wextra -Wpedantic`。
3. **可测试**：`make test` 一条命令跑完，全部通过；测试自身也不含越界调用。
4. **功能等价**：登录、注册、检索、借书、还书、续借、预约、罚款、停借、统计、CSV 持久化 —— 全部可走通。
5. **数据兼容**：能直接读 §1.1 的旧 `data/*.csv`（含 BOM 与中文状态值），写回后格式不变。
6. **观感**：Windows Terminal 里 100×30 显示正常：彩色、框线对齐、中文不糊不切、无频闪。
7. **手感**：菜单/列表方向键与 `getch` 单键响应，无需回车。
8. **文档同步**：`README.md` 状态改为"已按课程函数约束重构"，`docs/PRD.md` 的技术架构章节更新为 ANSI + getch 方案。
