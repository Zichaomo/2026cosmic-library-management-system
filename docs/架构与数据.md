## 文件格式

默认build/library-data，CSV为UTF-8、兼容可选BOM。读取支持引号内逗号、双引号转义、CRLF和尾空字段；非法UTF-8、字段溢出、非法引用/状态/库存拒绝，不能悄悄截断为另一条记录。

| 表 | 字段 |
| --- | --- |
| readers.csv | id,reader_no,name,password_hash,salt,phone,email,status,created_at |
| books.csv | id,isbn,title,author,total_copies,available_copies,status,created_at |
| loans.csv | id,book_id,reader_id,borrow_date,due_date,return_date,status,renew_count |
| fines.csv | id,reader_id,loan_id,amount_cents,created_at,status,paid_at |
| reservations.csv | id,book_id,reader_id,reserve_date,expire_date,status |

最多每表10000条，单字段缓冲512字节（包含终止符），具体校验以Schema为准。新建图书ID、记录ID稳定关联；图书编辑不改变这些引用。密码兼容旧FNV方案，新盐用rand仅作课程演示，不是生产级密码安全设计。

## 保存与恢复

state.0/state.1是交替的全表快照，包含代次、五表记录、COMMIT尾记录和校验。提交写非活动槽并验证完整性，再导出五张CSV。有效快照存在后，快照是权威数据，CSV是导出结果，不能手改CSV当作编辑数据库。

- 明确失败：业务回退未提交的内存改动。
- 已提交待导出：操作已成功，保留pending状态，不能重复业务；重新打开从快照导出。
- 提交状态不确定：阻止继续写，重新打开恢复后判断，不盲目重试。
- 新槽损坏但上一代有效：回退上一完整代次并提示recovered，最新修改可能丢失。
- 两槽损坏、必要文件缺失或不可读：停止，不静默建立空库或用混合CSV替代。

只承诺经过测试的单进程中断恢复，不保证fsync或断电落盘。没有外部独占保护，也没有多进程事务；用户人工保证同目录单实例。教材范围内尚无经过验证的完整多终端写入/异常锁恢复方案，仍暂缓。

## 输入、显示和搜索

getch阻塞；按键、进入页面和F5触发检查，没有空闲轮询、自动尺寸感知或后台通知。UTF-8字节、码点、显示列宽分开处理；普通可显示中文/ASCII用于编辑，秘密字段遮挡，不泄露明文到帧。实际输入法提交仍取决于终端环境。

main每帧通过fopen("CONOUT$","wb")输出并fclose，避免继承stderr不可写及缓冲不刷新的问题。它是Windows设备文件路径，非Win32函数；只适用于有控制台的Windows运行环境。ANSI备用屏幕和光标恢复同一路径，输出失败退出后保留可读提示。

拼音数据来自Unicode17.0 Unihan的kMandarin/kHanyuPinyin，44350汉字，元数据及许可位于tools/search/。运行时二分查静态C表，手写有界匹配；支持原文、全拼、首字母、大小写不敏感和混合输入，多读音按表尝试，ü映射v并接受u。空格、单引号、连字符忽略，支持ISBN省略连字符；不做错拼编辑距离或词义消歧，也不保证覆盖全部读音。读者记录范围先过滤，再关联搜索，不含密码散列/盐。
