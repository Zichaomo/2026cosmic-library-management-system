## 接口边界

- 文本容量按字节、包含 NUL；失败保留输出，输入须 NUL 结尾。复制/截断要求输入输出不重叠；拼接支持把自身或其后缀追加到自身。
- 显示列宽沿用普通中文与 ASCII 范围，拒绝控制字符、当前不支持的 Emoji/组合符；不宣称完整字素簇或任意终端字体兼容。
- 整数为已验证的 32 位 int，范围 -2147483648～2147483647；不接受空白、尾部杂字符或 `+`，副本数仍须大于 0。溢出先检查再计算。
- 日期范围 0001-01-01～9999-12-31，格式固定 `YYYY-MM-DD`；时刻格式为 `YYYY-MM-DD HH:MM:SS`。不把非法日期自动归一化。
- 日期加减和差值采用日历日序号；时刻转换固定北京时间 UTC+8，不依赖系统时区或夏令时。后续仓储再按业务限制允许的年份。
- 在本机 Windows GCC 验证 8 位字节、32 位 int、64 位 u64 和有符号整数 time_t；独立核对本机 `time()` 返回 Unix 秒数。该纪元假设是目标环境结论，不是所有 C 实现的保证。
- 仅 `cl_datetime_now()` 调用 `time()` 并识别 -1 错误值；普通 from_unix 转换允许时间戳 -1。
- 十六进制解码先验证完整输入再写入，拒绝奇数长度、非法字符和容量不足。u64 格式保持 16 位小写及前导零，供下一阶段旧 FNV 散列兼容使用；本阶段尚未迁移密码算法。
