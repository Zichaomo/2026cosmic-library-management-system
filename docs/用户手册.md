# 宇宙图书馆管理系统 · 用户手册

- 适用版本：v0.1（骨架阶段，本文按 [PRD](PRD.md) 目标功能编写）
- 运行平台：Windows 10 / 11（控制台程序）
- 技术栈：纯 C 语言 + Win32 控制台（字符画界面，支持鼠标点击）+ CSV 数据存储

> ⚠️ **开发状态说明**：系统当前处于骨架搭建阶段，下列功能按产品设计撰写。
> 尚未实现的功能在程序中会提示"未实现"，后续里程碑（M1~M4，见 PRD §8）逐步开放。

---

## 1. 系统简介

图书馆管理系统面向**管理员**与**读者**两类用户，覆盖图书馆业务核心闭环：

```
图书管理 → 读者管理 → 借书 / 还书 → 续借 / 预约 → 逾期罚款 → 统计报表
```

- 界面为控制台字符画（TUI）：框线窗口 + 颜色主题，**鼠标可点击**菜单、按钮、列表行
- 数据以纯文本 CSV 保存，可直接用记事本 / Excel 打开查看
- 单机使用，无需安装数据库

## 2. 启动与运行环境

### 2.1 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |

| 角色 | 账号 | 密码 |

## 5. 欢迎页：登录 / 注册（FR-101 ~ FR-106）

启动后进入欢迎页，提供四个可点击按钮：**登录 / 注册读者 / 帮助 / 退出**。

### 5.1 登录

- 输入**账号 + 密码**（密码显示为 `*`）
- `Tab` 切换字段，`Enter` 提交，`Esc` 返回
- 登录失败会提示具体原因：**账号不存在 / 密码错误 / 账号冻结**，且不会清空已输入的账号
- 登录成功后按角色进入：管理员主菜单 或 读者个人中心

### 5.2 注册读者

填写以下信息（均需通过格式与唯一性校验）：

| 字段 | 说明 |
|---|---|
| 姓名 | 必填 |
| 学号 / 工号 | 必填，**全校唯一**，重复会提示 |
| 密码 + 确认密码 | 两次输入需一致 |
| 联系方式 | 手机号 / 邮箱格式校验 |

> 密码不以明文存储：系统使用「FNV-1a 散列 + 随机盐」保存（FR-105），数据库文件中看不到明文。

### 5.3 退出

任何页面按 `Ctrl+Q` 或通过菜单退出登录，返回欢迎页（FR-106）。

## 6. 管理员功能

管理员登录后进入主菜单：

```
图书管理 | 字典管理 | 读者管理 | 借阅管理 | 预约管理 | 罚款管理 | 统计报表
```

### 6.1 图书管理（FR-301 ~ FR-306）

**图书字段**：ISBN、书名、作者、出版社、出版日期、分类、定价、馆藏总数、可借数、馆藏位置、简介、状态（在架 / 停借 / 注销）。

- **检索**：按 **ISBN / 书名 / 作者 / 分类** 模糊匹配，结果分页展示
- **新增**：录入图书资料与**馆藏副本数**（新增后"可借数 = 馆藏总数"，FR-305）
- **详情 / 编辑**：查看或修改图书资料
- **删除**：仅当该书**无未还副本**时可删除；有未还副本时只能**停借**（FR-302）
- **停借 / 恢复**：停借后该书不可再借出

> P1 增强：CSV 批量导入 / 导出图书（FR-306）。

### 6.2 字典管理：作者 / 出版社 / 分类（FR-304）

- 三个独立字典表，可**新增、编辑、删除**
- 删除时若**有图书引用**该字典项，系统会提示并阻止删除

### 6.3 读者管理（FR-401 ~ FR-404）

- **列表与检索**：按 学号 / 姓名 / 联系方式 模糊匹配
- **新增 / 编辑**：管理员可代读者建档、修改资料
- **冻结 / 解冻**：冻结后该读者**不可借书、不可续借**；解冻后恢复
- **注销**：逻辑删除读者
- **读者详情**：查看该读者的 借阅历史、当前借阅、预约队列、欠款总额（FR-403）

### 6.4 借阅管理（FR-501 ~ FR-506）

**借书**（FR-501/FR-502）：

1. 选择读者 + 图书（或直接输入图书 SN / ISBN）
2. 系统自动校验：
   - 图书存在且有**可借副本**
   - 读者状态正常、**未冻结**
   - 读者**未超借阅上限**（默认 5 本）
3. 借期默认 **30 天**（可在配置中修改），生成借阅单：借阅单号、读者、图书副本、借出时间、应还时间、状态

**还书**（FR-503）：

- 支持按**借阅单号**或**图书条码**归还
- 归还时自动计算是否逾期，**逾期自动生成罚款单**

**续借**（FR-504）：

- 有借阅记录且**未逾期**时可续借：**1 次、15 天**
- **预约队列有人排队时禁止续借**

**逾期列表**（FR-505）：

- 全局展示所有逾期未还记录，**红色突出**显示

> P1 增强：登录时状态栏提示"N 本应还、M 本逾期"（FR-506）。

### 6.5 预约管理（FR-601 ~ FR-604）

- 图书**无可借副本**时，读者可**预约**，进入该书等待队列
- 归还时按**预约顺序**通知：为排到队首的读者**保留副本 2 天**，超时未取自动**顺延**给下一位
- 管理员可查看 / 处理预约队列
- 预约状态：排队中 / 可借 / 已过期 / 已取消

### 6.6 罚款管理（FR-701 ~ FR-704）

- **生成**：逾期自动计算，默认 **0.5 元/天**（可配置），归还当天生成罚款单
- **缴纳**：读者可自助缴费（模拟支付），**管理员也可代收**
- **自动冻结**：欠款超过阈值（默认 **10 元**）自动冻结该读者借阅权限，**补缴后自动恢复**
- 罚款单信息：单号、读者、关联借阅单、金额、生成时间、状态（未缴 / 已缴）、缴费时间

### 6.7 统计报表（FR-801 ~ FR-806）

| 报表 | 内容 |
|---|---|
| 馆藏统计 | 总量、可借、借出、停借数量 |
| 分类分布 | 各分类数量与占比 |
| 借阅统计 | 本月 / 累计的借出、归还、续借次数 |
| 逾期清单 | 逾期未还明细 |
| 罚款统计 | 罚款总收入、未缴罚款明细 |
| 排行榜 | 最热图书 Top10、活跃读者 Top10（按借阅次数） |

> P1 增强：报表导出 CSV（FR-806）。

## 7. 读者个人中心

读者登录后进入个人中心：

```
图书检索与详情 | 我的借阅 | 我的预约 | 我的罚款
```

| 功能 | 说明 |
|---|---|
| 图书检索与详情 | 检索图书、查看详情（含可借数 / 馆藏位置） |
| 我的借阅 | 当前借阅列表；支持**自助续借**（限 1 次 15 天）、还书申请 |
| 我的预约 | 查看 / **取消**预约；状态显示：排队中 / 可借 / 已过期 / 已取消 |
| 我的罚款 | 查看罚款单明细，**在线缴纳**（模拟支付，记录缴费时间） |

## 9. 数据文件说明

所有数据保存在项目根目录的 `data/` 文件夹（UTF-8 带 BOM 编码，可直接用记事本 / Excel 查看）：

| 文件 | 内容 |
|---|---|
| `books.csv` | 图书（含副本数、状态） |
| `authors.csv` / `publishers.csv` / `categories.csv` | 作者 / 出版社 / 分类字典 |
| `readers.csv` | 读者（密码为散列值，非明文） |
| `loans.csv` | 借阅单 |
| `reservations.csv` | 预约 |
| `fines.csv` | 罚款单 |
| `meta.csv` | 自增 ID 计数与系统配置（`loan_days`、`fine_per_day` 等） |

> 程序每次写操作采用**原子保存**（先写临时文件再替换），异常退出不会损坏已保存的数据。

## 10. 常见问题（FAQ）

**Q1：界面出现乱码 / 框线错位？**
请将控制台字体设置为「新宋体」或等宽字体，并把窗口调大到至少 100×30。

**Q2：提示窗口太小？**
按 PRD FR-206，系统检测到窗口小于 100×30 时会提示，请调整窗口大小后按 `F5` 刷新。

**Q3：忘记密码怎么办？**
读者请联系管理员重置；管理员账号密码丢失需联系系统维护人员处理（或删除 `data/meta.csv` 中对应记录重新初始化，注意会同时清除其他配置）。

**Q4：数据存在哪里？能不能直接看？**
所有数据在 `data/` 下的 CSV 文件中，UTF-8 带 BOM，可直接用 Excel 打开；但**请勿在程序运行时手动编辑**，以免覆盖丢失。

**Q5：程序异常退出会不会丢数据？**
不会。写入采用原子保存，最近一次已保存的数据完整保留。

**Q6：为什么不能删某本书？**
该书存在未还副本，系统禁止删除（FR-302），可改为「停借」。

**Q7：为什么不能借书 / 续借？**
请检查：读者是否被冻结、是否超借阅上限、是否欠款超阈值、该书是否停借或无可借副本、续借是否已有预约排队。
