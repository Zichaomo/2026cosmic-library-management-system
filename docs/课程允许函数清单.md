更新日期：2026-10-21。重构顺序与验收标准见 [plan.md](plan.md)。

## 1. 依据与范围

按仓库此前记录的老师口径，教材《C 程序设计教程与实训（第 2 版）》附录 C 的函数，以及正文讲解或使用的函数均可使用。附录 C 为 66 个，现有正文补充表实际列出 9 个不同函数名，共 75 个。旧文档的“正文另外 6 个”属于计数错误。

下面保留此前整理的教材出处；2026-10-21 本轮没有重新核验教材 PDF 或 OCR 原件。后续如需更改许可范围，应核对教材依据并记录变更。

自写函数、循环、结构体、typedef 和宏属于 C 语言实现手段；自写函数内部的外部调用仍须符合白名单。包含允许头文件不代表其中所有函数均可调用。

## 4. 头文件与类型

按现有项目约束，直接包含的系统头文件范围为：

- `<stdio.h>`：输入输出与文件操作。
- `<string.h>`：六个允许的字符串函数；补充函数的可用声明需按目标工具链核对。
- `<ctype.h>`：字符分类与转换。
- `<math.h>`：数学函数。
- `<malloc.h>`：教材内存分配函数。
- `<conio.h>`：正文允许的 `getch`、`getche`。
- `<stdlib.h>`：`rand`、`srand`、`abs`、`exit` 等实际声明；教材表格分类不等于标准头文件归属。
- `<time.h>`：`time` 和 `time_t`；不因此允许 `mktime`、`localtime` 等其他时间函数。

项目自写 `include/base_types.h` 提供 `bool`、`true`、`false` 以及 `u8`、`u16`、`u32`、`u64`。按现有重构约定不直接包含 `<stdbool.h>`、`<stdint.h>`、`<stddef.h>`、`<limits.h>`、`<errno.h>`。

`size_t`、`FILE`、`NULL`、`EOF`、`SEEK_SET` 可从 `<stdio.h>` 获得，不重复定义。`INT_MAX`、`CHAR_BIT`、`SIZE_MAX` 不保证由 `<stdio.h>` 提供，不能把某个工具链的间接包含当作通用保证；需要时使用经过范围验证的项目自定义常量。`u32`、`u64` 的位宽须在目标工具链验证，可用 C11 的 `_Static_assert` 和 `sizeof` 辅助检查。

错误处理依据函数返回值、`feof()` 和 `ferror()`；不依赖 `errno` 或其底层实现函数。

## 5. 实现边界

1. ANSI 转义序列在 2026-10-16 的项目记录中已确认可用，以 `printf` 等允许函数输出。终端须支持 VT；不在程序中调用 Win32 设置 API 或 `system()` 配置终端。
2. `gets` 虽列于教材，但已从 C11 移除，本项目不使用。`fgets` 同样位于白名单，可用于有容量限制的行输入；中文输入与即时编辑仍需在真实终端验证。
3. UTF-8 的字节数、字符数与显示列宽不同，复制、截断、光标移动和退格须分别处理，不得切碎字符。
4. `getch()` 是阻塞输入。仅替换输入函数不能保留原来无按键时每秒自动同步的能力，实施取舍见计划。
5. `rand()` 的具体上界按目标工具链处理，不写死教材示例中的 32767；随机盐仅用于课程演示。
6. `strcpy`、`strcat` 在白名单中，但调用前必须保证容量；不因许可而省略边界检查。

## 6. 常见清单外调用与替代方向

| 清单外调用 | 替代方向 |
| --- | --- |
| `memset`、`memcpy`、`memmove`、`memcmp` | 初始化或手写循环，处理重叠方向 |
| `sprintf`、`snprintf`、`vsnprintf` | 直接输出或自写有容量限制的格式化 |
| `strncpy`、`strncat`、`strncmp`、`strtok`、`strpbrk` | 自写边界明确的复制、比较和解析 |
| `atoi`、`atof`、`strtol`、`sscanf` | 自写校验和数字解析，检查范围与尾部内容 |
| `fflush`、`setvbuf` | 验证允许输出方式在真实终端的显示时机，不偷偷保留调用 |
| `mktime`、`localtime`、`localtime_s`、`strftime`、`difftime`、`clock` | `time()` 配合自写日历与日期运算 |
| `qsort`、`bsearch` | 自写排序、查找 |
| `remove`、`_wfopen`、`MoveFileExW`、`DeleteFileW` | 允许的文件函数配合经验证的保存和恢复协议；外部脚本清理测试目录 |
| `kbhit`、`Sleep`、`WaitForSingleObject`、`CreateMutexW` | 不直接替换为忙等或不可靠锁文件；单独验证同步方案 |
| 全部 Win32 控制台 API、宽字符库、BCrypt、`gotoxy`、`textcolor`、`clrscr` | ANSI 输出、UTF-8 工具及经过目标环境验证的输入方案 |

此表仅为常见例子。最终检查应核对全部外部调用与白名单，覆盖源码、头文件、测试和工具；不能将“未被禁用正则命中”当作合规证明。
