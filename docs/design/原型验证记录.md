# C 界面原型验证记录

日期：2026-10-21。当前版本为 120×35；下方早期 120×40 的实测为历史记录，最新结果见文末。对象：`tools/preview/` 独立原型；不代表正式系统完成重构。

## 已实现

- 120×40 暖白、暖石、浅鼠尾草绿三类页面：演示登录、图书列表、新增图书。
- 20 条初始内存样例、8 条/页、中文检索、详情、增副本、停借/恢复；新增后仍只存在内存。
- 表单焦点、普通中文与 ASCII 的插入、删除、左右/Home/End、水平滚动、密码遮挡。
- 校验失败保留字段；未保存表单返回时可选择放弃或继续。
- ANSI 真彩色输出；比较字符网格，只输出有变化的行。无按键时阻塞等待，不定时清屏、不忙等。
- 交互画面通过 `fwrite(..., stderr)` 输出，利用目标 Windows CRT 的无缓冲错误流，去掉旧原型的 `fflush()`。

## Windows 伪终端实测

使用工具提供的 Windows 交互 PTY/ConPTY，启动前在外部执行 `chcp 65001`；测试会话用外部 `mode con cols=120 lines=40` 准备大小。正式 C 代码不调用这些命令。

| 项目 | 操作与观察 |
| --- | --- |
| 无强制刷新函数的输出 | 输入探针在等待第一个 `getch()` 前已显示提示；原型初始页也在按键前输出 |
| 默认编码影响 | 默认代码页输入“中文”得到 214、208、206、196，即 GBK 字节 |
| UTF-8 编码 | 65001 下同样输入得到 228、184、173、230、150、135，即 UTF-8 字节 |
| 扩展键 | 上、左、Delete、F5 经过 PTY 后收到 `getch()` 扩展前缀和相应键码 |
| 演示登录 | 输入 admin、Tab、admin123、Enter、Enter；输出登录成功并进入列表 |
| 中文中间编辑 | 在新表单输入“中文书籍”，左移两次、插入“测试”、Delete 后补回“书”；得到“中文测试书籍” |
| 中文作者与退格 | 输入“张老师”，退格再输入“师”，保留完整“张老师” |
| 错误保留与修正 | 副本数改为 0，提交显示错误；改为 2 后加入列表，书名作者仍完整 |
| 分页与检索 | PgUp 到中间页，`/` 输入“中文”检索；能找到新输入的书名 |
| 静置无输出 | 程序等待按键期间再次读取会话，无新增输出；不是定时重绘 |
| 正常退出 | Ctrl+Q 后退出码 0，并输出恢复可见光标的序列 |

这些结果证明当前工具链和 ConPTY 下的行为，不冒充人工观察窗口、真实输入法候选过程或不同电脑的视觉验收。

## 源码函数审计

对原型 `.c/.h` 的项目函数、外部调用和包含头文件做了静态核对。当前使用的外部函数名：

`fclose`、`ferror`、`fgets`、`fopen`、`fputc`、`fputs`、`fread`、`ftell`、`fwrite`、`getch`、`printf`、`rewind`、`strcmp`、`strlen`、`strstr`。

均在项目白名单中；直接系统头只有 `<stdio.h>`、`<string.h>`、`<conio.h>`。本结论按源码中的显式调用核对，不要求编译器与 C 运行库内部只能使用这些函数。Python/PowerShell 只作为外部设计、启动和验证工具，不是应用实现的一部分。

## 可见窗口与强制重绘修复

针对用户实际截图中登录卡片底部被截断、放大窗口后仍未恢复的问题：

- 启动脚本不再使用 `mode con` 强设缓冲/窗口尺寸，而是检查 `$Host.UI.RawUI.WindowSize` 的可见行列数。低于 120×40 时停留在文字提示中；用户调整后按 Enter 复查，Ctrl+C 取消。
- F5 在登录、列表、表单和覆盖层上均绕过“内容未改变则不输出”的缓存，完整重画当前场景；不重置字段或导航状态。平时仍只输出变化行。
- 交互模式进入 ANSI 独立屏幕缓冲区，退出时恢复主屏和光标，减少与 PowerShell 历史滚动混合的影响；不改变 C 函数许可范围。
- Windows ConPTY 实测：80×24 时启动脚本显示尺寸提示，没有进入半截 TUI；在 120×40 测试会话中，登录页 F5 输出完整画面，Ctrl+Q 正常退出并恢复主屏。
- 自动检查现为 61 项通过、0 失败，包含内容未改变时显式强制重绘的回归检查。

固定 120×40 布局不会因窗口变大而自动放大控件或增加行间距；刷新与自动排版是不同能力。本轮修复尺寸不够时的错误启动和窗口变化后的画面恢复，尚未实现自动检测运行中缩放或响应式布局。实际字体仍由用户终端设置。
