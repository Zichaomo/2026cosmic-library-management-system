# 数据与认证模块

`src/migration/` 和 `include/migration/` 提供 CSV、Schema、两槽快照、账号认证与流通规则，当前 C 应用已经使用这些模块，不链接 BCrypt。

数据格式、提交状态和恢复规则见[架构与数据](../../docs/架构与数据.md)，初始化与运行见[运行说明](../../docs/运行说明.md)。创建独立演示数据可在项目根目录执行：

```text
make run DATA_DIR=build/demo
```

已有目录不重新初始化。五张 CSV 建立快照后成为导出结果，不要手改 CSV 或重新写入 EMPTY 标记。跨版本导入需要准备完整的五表副本、核对格式与引用，在新目录验证；不能向现有快照目录直接覆盖文件。

`tests/test_migration.c` 是保留的迁移测试源码，完整运行依赖特定旧实现样本和异常场景前置条件。当前 Makefile 不提供 `test-migration` 目标；现行 `make test` 的范围与历史结果区别见[验证记录](../../docs/验证记录.md)。

认证保留旧 FNV 密码兼容和 UTF-8 编码规则；新随机盐仅限课程演示。密码框使用掩码，普通字段的显示列宽与秘密字段的编码校验分别处理，不能据此宣称支持所有 Unicode 字素簇。
