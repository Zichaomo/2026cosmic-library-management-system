## 使用与演示

解压源码，在支持ANSI真彩色的Windows Terminal或VS Code终端打开项目目录，将Windows GCC和make放入PATH，窗口至少120×35。

```powershell
make run
```

不使用make时执行tools/run-library.ps1。首次自动准备build/library-data：管理员admin/admin123，读者reader001/reader123，20种各3册图书。之后启动保留修改，不重置；正式旧data/不会使用。直接运行exe不能获得启动器的单写者保护，演示时始终从脚本进入。

建议演示顺序：注册/登录 → 图书目录K检索 → J借书并确认 → 我的借阅X续借/G归还 → 管理员图书/读者/预约/罚款/统计 → 退出再启动核对记录。预约需先借完可借副本；罚款依真实日期与规则计算，不手改权威快照。

各页面显示当前可用按键，F1帮助，F5刷新，Ctrl+Q退出。输入框左右移动光标、直接插入、Home/End、Backspace/Delete。缩放后放大到足够尺寸，按F5恢复。无按键时不自动刷新，不支持鼠标和窗口自适应。

## 源码包

tools/package_delivery.py生成build/delivery/single-process-source-GUID.zip，包含活动源码、测试、工具、文档、VS Code任务和legacy兼容参照。包内DELIVERY-MANIFEST.json逐文件SHA-256；生成后解压并核对字节哈希。build/delivery/latest.json记录最新包、解压验收目录和ZIP哈希。

源码ZIP不内嵌.git目录；交付目录另附history.bundle，保留所有可达分支与提交历史，可用git clone <history.bundle路径> <新目录>恢复。用户要求分批commit，原仓库历史不重写。源码ZIP不包含用户运行CSV、快照、build/、exe或Python缓存。解压后首次运行生成自己的样本。该包为可构建源码交付候选，保留已说明的限制，不擅自改为“最终版”承诺。原仓库及数据不移动、不清理。未提交或推送Gitee。
