

# 2026宇宙图书馆管理系统

## 项目概述

2026宇宙图书馆管理系统是一个基于纯C语言开发的图书馆管理解决方案，采用Win32 API实现图形界面，支持CSV数据存储，适用于中小型图书馆的日常运营管理。

## 技术架构

- **编程语言**: 纯C语言，单工程结构
- **图形界面**: Win32 API（支持鼠标交互）
- **数据存储**: CSV格式
- **开发环境**: 支持Visual Studio Code（C/C++配置）
- **跨平台**: 预留跨平台支持接口

## 主要功能模块

### 核心功能（P0级别）

1. **账号与登录**
   - 用户身份验证
   - 权限管理

2. **控制台图形界面框架**
   - Win32窗口程序
   - 鼠标交互实现

3. **图书管理（管理员）**
   - 图书信息录入
   - 图书查询与检索

4. **读者管理（管理员）**
   - 读者信息管理
   - 读者权限设置

5. **借阅/归还/续借**
   - 图书借阅处理
   - 图书归还管理
   - 借阅续借功能

### 扩展功能（P1级别）

6. **预约功能**
   - 图书预约
   - 预约管理

7. **罚款管理**
   - 逾期罚款
   - 罚款记录

8. **统计报表**
   - 借阅统计
   - 报表生成

## 数据设计

系统采用CSV格式进行数据存储，包含以下数据表：
- 图书信息表
- 读者信息表
- 借阅记录表
- 预约记录表
- 罚款记录表

## 开发环境配置

### Visual Studio Code配置

项目包含.vscode配置文件夹，需安装以下扩展：
- C/C++（Microsoft）
- C/C++ Extension Pack

