# 独立演示入口

正常工程 `src/main.c` 和普通 `build/library.exe` 不启用重置，仍然持久保存数据。

这里的替代入口只为阶段简报演示构建。演示根目录必须有 `build/library.exe`、`data`、`初始数据备份` 和内容以 `library-demo-reset-v1` 开始的 `demo-mode.txt`，缺少标识或任一模板时拒绝运行。

演示首次启动会恢复五类 CSV。每个进程在整个应用生命期持有一个按绝对根目录区分的 Win32 命名互斥量句柄。后续进程等待初始化完成，不重复恢复。所有进程退出后，该内核对象消失，下次启动重新恢复。只退出登录不结束演示轮次。

编译时使用这里的 main.c 和 demo_session.c，链接正常 src 下除 main.c 以外的源文件，避免把演示逻辑放进正常入口。修改展示程序时，同步重新编译这个入口。

模板属于演示数据，请不要指向真实 data 的目录联接。重置前拒绝模板和目标的目录联接/重解析点。
