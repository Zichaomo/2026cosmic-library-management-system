## 使用与演示

解压源码，在支持ANSI真彩色的Windows Terminal或VS Code终端打开项目目录，将Windows GCC和make放入PATH，窗口至少120×35。

```powershell
make run
```

不经make时可直接执行 `start\CosmicLibrary.exe --data build/library-data`（首次需先 `make prepare` 准备目录）。首次自动准备build/library-data：管理员admin/admin123，读者reader001/reader123，20种各3册图书。之后启动保留修改，不重置；正式旧data/不会使用。原启动器tools/run-library.ps1已移除，不再有单写者保护，演示时由人工保证只开一个实例。

建议演示顺序：注册/登录 → 图书目录K检索 → J借书并确认 → 我的借阅X续借/G归还 → 管理员图书/读者/预约/罚款/统计 → 退出再启动核对记录。预约需先借完可借副本；罚款依真实日期与规则计算，不手改权威快照。

各页面显示当前可用按键，F1帮助，F5刷新，Ctrl+Q退出。输入框左右移动光标、直接插入、Home/End、Backspace/Delete。缩放后放大到足够尺寸，按F5恢复。无按键时不自动刷新，不支持鼠标和窗口自适应。

## 源码包

本地工具tools/package_delivery.py（已取消跟踪）生成build/delivery/single-process-source-GUID.zip，包含活动源码、测试、工具、文档、VS Code任务和legacy兼容参照。包内DELIVERY-MANIFEST.json逐文件SHA-256；生成后解压并核对字节哈希。build/delivery/latest.json记录最新包、解压验收目录和ZIP哈希。
